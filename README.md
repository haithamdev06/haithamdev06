### 🚀 About Me

I'm a third-year Computer Engineering student currently interning in QA, where I spend my days finding the edge cases nobody thought to check. That habit is pulling me toward cybersecurity — same instinct, higher stakes.  
In between, I build for the web and ship side projects to see what breaks.  
🔍 Currently: automated testing with TypeScript &amp; Playwright  
🛡️ Heading toward: security research and pentesting  
🌐 Also fluent in: making things that live in a browser  
💡 Always up for: a project that teaches me something new

🔭 &nbsp;I'm currently working on **Building A Garage Management System Website**
